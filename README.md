# 📚 Library System

Современная информационная система управления библиотекой, разработанная в рамках дипломного проекта.

Система предназначена для автоматизации работы библиотеки: управления книжным фондом, пользователями и читателями. Проект предоставляет удобный интерфейс как для администрации библиотеки, так и для зарегистрированных читателей.

---

## ✨ Возможности

### 👨‍💼 Для администратора

* Управление книгами (добавление, редактирование, удаление)
* Загрузка обложек книг
* Управление пользователями
* Назначение ролей (Суперадминистратор, Администратор, Читатель)
* Просмотр каталога книг
* Управление количеством экземпляров
* Безопасное хранение паролей с использованием `password_hash()`

### 👤 Для читателя

* Регистрация нового аккаунта
* Авторизация
* Просмотр каталога книг
* Просмотр информации о книгах
* Личный кабинет
* Редактирование профиля

## 🔒 Безопасность

В проекте реализованы современные механизмы защиты:

* Использование **Prepared Statements** для предотвращения SQL-инъекций
* Хэширование паролей с помощью `password_hash()`
* Проверка авторизации пользователей
* Разграничение доступа на основе ролей
* Серверная валидация пользовательских данных

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/library-system.git
```

### 2. Перемещение проекта

Скопируйте проект в каталог вашего локального веб-сервера.

Поддерживаются:

* OpenServer
* XAMPP
* Laragon

---

### 3. Создание базы данных

Создайте базу данных:

```text
library_system
```

---

### 4. Импорт базы данных

Импортируйте файл:

```text
database.sql
```

через phpMyAdmin или другой клиент MySQL.

---

### 5. Настройка подключения

Отредактируйте параметры подключения в файле конфигурации.

```php
$host = "localhost";
$dbname = "library_system";
$user = "root";
$password = "";
```

---

### 6. Запуск проекта

Откройте в браузере:

```text
http://localhost/library-system
```
