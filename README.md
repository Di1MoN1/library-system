# 📚 Library System

Современная информационная система управления библиотекой, разработанная в рамках дипломного проекта.

Система предназначена для автоматизации работы библиотеки: управления книгами, читателями и пользователями, а также предоставляет удобный интерфейс для администратора и читателей.

---

# ✨ Основные возможности

## Для администратора

* Управление книгами (добавление, редактирование, удаление)
* Загрузка обложек книг
* Управление пользователями
* Назначение ролей (Администратор / Суперадминистратор / Читатель)
* Просмотр каталога книг
* Управление количеством экземпляров книг
* Безопасное хранение паролей с использованием `password_hash()`

## Для читателя

* Регистрация нового аккаунта
* Авторизация
* Просмотр каталога книг
* Личный кабинет
* Просмотр информации о книгах
* Редактирование профиля

# 🔒 Безопасность

В проекте реализованы современные подходы к безопасности:

* Prepared Statements для защиты от SQL-инъекций
* Хэширование паролей через `password_hash()`
* Проверка авторизации пользователей
* Разделение доступа по ролям

# 🚀 Установка проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/USERNAME/library-system.git
```

### 2. Скопировать проект в папку веб-сервера

Например:

* OpenServer
* XAMPP
* Laragon

---

### 3. Создать базу данных

Создайте базу данных:

```
library_system
```

---

### 4. Импортировать базу

Импортируйте файл

```
database.sql
```

через phpMyAdmin.

---

### 5. Настроить подключение

Укажите параметры подключения к базе данных в файле конфигурации.

Пример:

```php
$host = "localhost";
$dbname = "library_system";
$user = "root";
$password = "";
```

---

### 6. Запустить проект

Откройте браузер:

```
http://localhost/library-system
```
