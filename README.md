# 📚 Library System

Современная информационная система управления библиотекой, разработанная в рамках дипломного проекта.

Система предназначена для автоматизации работы библиотеки: управления книжным фондом, пользователями и читателями. Проект предоставляет удобный интерфейс как для администрации библиотеки, так и для зарегистрированных читателей.

---

## ✨ Возможности

### 👨‍💼 Для администратора

* Управление книгами (добавление, редактирование, удаление)
* Загрузка обложек книг
* Управление пользователями
* Назначение ролей (Суперадминистратор, Администратор, Читатель)
* Просмотр каталога книг
* Управление количеством экземпляров
* Безопасное хранение паролей с использованием `password_hash()`

### 👤 Для читателя

* Регистрация нового аккаунта
* Авторизация
* Просмотр каталога книг
* Просмотр информации о книгах
* Личный кабинет
* Редактирование профиля

## 🔒 Безопасность

В проекте реализованы современные механизмы защиты:

* Использование **Prepared Statements** для предотвращения SQL-инъекций

* Серверная валидация пользовательских данных

## 📂 Структура проекта
library-system/
├── admin/                     — панель администратора
│   ├── reports/                   — отчёты (популярные книги, активные читатели, статистика, просрочки)
│   ├── requests/                  — обработка заявок читателей (approve/reject/issue)
│   ├── settings/                  — настройки библиотеки (срок выдачи)
│   └── index.php                  — дашборд со статистикой и графиком
├── assets/
│   ├── css/style.css              — единый стиль проекта
│   ├── images/                    — обложки книг (20 файлов)
│   └── js/script.js
├── authors/                   — CRUD авторов
├── books/                     — CRUD книг + каталог + страница книги
├── borrowings/                — журнал выдач (выдать/вернуть/удалить)
├── config/db.php              — подключение к БД
├── database/library_db.sql    — дамп структуры БД (сейчас пустой ⚠️)
├── genres/                    — CRUD жанров
├── includes/                  — общие部分и: header, navbar (с уведомлениями), footer, book-card, functions
├── overdue/                   — список просроченных книг
├── reader/                    — личный кабинет читателя
│   ├── catalog.php, book.php      — каталог и страница книги для читателя
│   ├── my_books.php, requests.php — мои книги / мои заявки
│   ├── profile.php                — личный кабинет
│   ├── register.php, login.php    — регистрация / вход читателя
│   └── request.php, request_return.php — заявки на выдачу/возврат
├── readers/                   — CRUD читателей (со стороны админа)
├── return_requests/           — заявки на возврат (обработка админом)
├── users/                     — управление администраторами (superadmin)
├── README.md                  — уже есть в проекте
├── index.php                  — публичный каталог (доступен без входа)
├── login.php / logout.php     — вход/выход администратора
```

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/library-system.git
```

### 2. Перемещение проекта

Скопируйте проект в каталог вашего локального веб-сервера.

Поддерживаются:

* OpenServer
* XAMPP
* Laragon

---

### 3. Создание базы данных

Создайте базу данных:

```text
library_system
```

---

### 4. Импорт базы данных

Импортируйте файл:

```text
database.sql
```

через phpMyAdmin или другой клиент MySQL.

---

### 5. Настройка подключения

Отредактируйте параметры подключения в файле конфигурации.

```php
$host = "localhost";
$dbname = "library_system";
$user = "root";
$password = "";
```

---

### 6. Запуск проекта

Откройте в браузере:

```text
http://localhost/library-system
```
